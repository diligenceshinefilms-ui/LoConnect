# LoConnect

LoConnect is an app to help connect local communities. This repository contains the initial Vite + React + TypeScript skeleton and a small To‑Do application that stores tasks in localStorage.

Features in this commit
- Vite + React + TypeScript
- Minimal project structure
- To‑Do application with persistence using localStorage

Quick start

1. Install dependencies

   npm install

2. Run development server

   npm run dev

3. Build for production

   npm run build

Usage

- Open the app in your browser (Vite opens automatically by default).
- Use the To‑Do section to add, toggle, and delete tasks. Tasks are saved in your browser's localStorage.
